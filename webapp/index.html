Earlier accuracy figures are withdrawn. DFC2019 Track 3 satellite frames are not orthorectified — they carry an RPC camera model and no geotransform — so resizing the north-up LiDAR raster onto them, which this project did everywhere, scored two different pieces of ground. That invalidates the 4.64 m RMSE headline and the RS3DAda comparison alongside it, since both used the same pairing. Input now goes through the RPC orthorectifier and each tile's registration is checked before it is scored; the table above shows whatever the current run measured.
Forest is the weakest class and the reason is structural, not tuning: shadow-based height measurement targets crisp building rooflines, while tree canopy casts diffuse, overlapping shadows with no clean edge to measure against.
